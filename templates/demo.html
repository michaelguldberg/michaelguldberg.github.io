How Claude Code Works

This page is a live example — it was created automatically by Claude Code in response to a GitHub issue.

1 Open a GitHub Issue

You write a request in plain English as a GitHub issue on your repository. For example: "Give me an example of how this works."

2 Claude Code Reads the Codebase

Claude Code reads your existing files (index.html, templates/, main.css, etc.) to understand the structure and style of your project before making any changes.

3 Changes Are Made on a Branch

All changes happen on a dedicated branch (e.g., claude/create-example-demo-jv1Fa), so your main branch is never touched directly.

4 Commit & Push

Claude Code commits the changes with a descriptive message and pushes the branch to GitHub, ready for your review.

5 You Review & Merge

You review the pull request, request changes if needed, and merge when you're happy. You stay in full control.
